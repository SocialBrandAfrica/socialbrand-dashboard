2026-06-13 (Pieter). Standing method, ratified RULE-BOOK R27 §19 clause 8.

A new term/metric is never one flat rule. Split across layers:
- **L1 precondition:** facts must be commensurate (same grain, unit, definition, source) or nothing above is valid.
- **L2 mechanism (pantry):** pure calculations + the full set of variant pieces/flags a recipe might need. No policy.
- **L3 recipe:** per-scenario choice, surfaced, never baked down into L2/L1. Stock once, choose per scenario.

**Worked example — like for like (RULE-BOOK §1; TY vs LY ALWAYS like for like):** L1 commensurable facts; L2 the 364-day shift pairing + both-year totals + line-present-LY/TY + day-complete flags; L3 recipe = floor (LY mirrors on-screen stores/filter/dates) + variables (whole-range vs same-line-only; completeness exclusion). Engine stocks both whole-range total and same-line flags → both LY versions from one engine, no re-extract. Implication for dashboard: today's LY is selection+date aligned but NOT same-line restricted; same-line LFL is a build if a scenario asks for it.
