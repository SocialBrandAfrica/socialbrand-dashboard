Ratified 2026-06-13 as RULE-BOOK §18 R26 (read it there in full).

The main road = North Star: accurate stock ledgers → automated DIWAAIS ordering, on the L1 ingest → L2 engine → L3 display spine. That endgoal does not move.

Everything else is a parallel improvement, never the destination: petals/applets, the stocktake engine, Pulse Mini, cleanup tools, design rounds, one-off audits. A tributary hands its value back to the main road and the road carries on.

**Why:** sessions on side tracks kept rewriting the project scope and promoting tributaries to the endgoal (the 06-13 design-drift and the lost source-migration thread). That is a governance breach, same class as a future-dated file or a second handover.

**How to apply:** before any new thread, state which North Star goal it serves. If none, do not start it. Scope changes come ONLY from Pieter as an explicit ruling against the North Star, never from one session's momentum. If a side track pulls focus off the spine, stop and flag it for PM to re-anchor. See also project_dash_source_migration.md (the main-road dashboard thread).
