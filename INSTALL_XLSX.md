# One-time step — install the Excel library

The new dashboard builds Excel files directly in the browser using a library called `xlsx`.
You need to install it once before starting the app.

## Steps

1. Open a terminal in the `socialbrand-dashboard` folder  
   (In VS Code: Terminal → New Terminal — it should already be in the right folder)

2. Run this command:

   ```
   npm install
   ```

3. Then start the app as normal:

   ```
   npm run dev
   ```

That's it. You only need to do the `npm install` step once.
After that, just `npm run dev` each time as usual.
